项目概述

Ripple Satellite Planner 是一个基于涟漪模型的动态卫星搜索任务规划系统。 系统接收目标位置、候选卫星任务等信息，通过贪心策略规划出最优的任务执行序列， 以最大化搜索到目标的概率。

应用名称: ripple-satellite-planner
技术栈: Spring Boot + JTS (Java Topology Suite) + Lombok
数据格式: JSON (Jackson 序列化，日期格式: yyyy-MM-dd HH:mm:ss，时区: GMT+8)

接口列表

POST /api/v1/plan 核心接口 ▾

执行任务规划。接收规划请求，调用 RippleTaskPlanner 执行贪心策略规划，返回任务序列。

请求参数

参数名类型必填说明
centerLondouble是搜索中心点经度，范围 -180.0 到 180.0
centerLatdouble是搜索中心点纬度，范围 -90.0 到 90.0
entityIDstring是目标实体标识，用于涟漪模型区分不同目标
targetLastFindTimestring是目标最后被发现的时刻，格式: yyyy-MM-dd HH:mm:ss
targetSpeeddouble是目标估计速度，影响涟漪扩散范围
startTimestring是规划起始时间，格式: yyyy-MM-dd HH:mm:ss
candidateTasksTaskParam[]是初始候选任务池，包含所有可供选择的任务

TaskParam 结构

参数名类型必填说明
taskIDstring是任务唯一标识符
satellitestring是执行该任务的卫星标识
scoutTimestring是侦察时间，格式: yyyy-MM-dd HH:mm:ss
catasCata[]是该任务的覆盖区域列表，由多个四边形组成

Cata 结构（四边形区域）

参数名类型必填说明
catalbLatitudeDouble是左下角纬度 (Left Bottom Latitude)
catalbLongitudeDouble是左下角经度 (Left Bottom Longitude)
catartLatitudeDouble是右上角纬度 (Right Top Latitude)
catartLongitudeDouble是右上角经度 (Right Top Longitude)
cataltLatitudeDouble是左上角纬度 (Left Top Latitude)
cataltLongitudeDouble是左上角经度 (Left Top Longitude)
catarbLatitudeDouble是右下角纬度 (Right Bottom Latitude)
catarbLongitudeDouble是右下角经度 (Right Bottom Longitude)

请求示例

// POST /api/v1/plan // Content-Type: application/json { "centerLon": 116.4, "centerLat": 39.9, "entityID": "TARGET_001", "targetLastFindTime": "2026-07-01 08:00:00", "targetSpeed": 10.0, "startTime": "2026-07-01 09:00:00", "candidateTasks": [ { "taskID": "TASK_001", "satellite": "SAT_01", "scoutTime": "2026-07-01 10:00:00", "catas": [ { "catalbLatitude": 39.8, "catalbLongitude": 116.3, "catartLatitude": 40.0, "catartLongitude": 116.5, "cataltLatitude": 40.0, "cataltLongitude": 116.3, "catarbLatitude": 39.8, "catarbLongitude": 116.5 } ] } ] }

响应参数

参数名类型说明

SearchRecord 结构

参数名类型说明

响应示例

数据模型详解

PlanningRequest（规划请求）

centerLon double
搜索中心点经度，通常是目标最后已知位置
centerLat double
搜索中心点纬度
entityID String
目标实体标识，涟漪模型据此区分不同目标
targetLastFindTime String
目标最后被发现的时刻，格式: yyyy-MM-dd HH:mm:ss
targetSpeed double
目标估计速度，影响涟漪扩散范围
startTime LocalDateTime
规划起始时间，即 PlannerState.currentTime 的初始值
candidateTasks List<TaskParam>
初始候选任务池，包含所有尚未执行、可供 Planner 选择的任务

TaskSequenceResult（规划结果）

taskSequence List<TaskParam>
按执行时间升序排列的任务序列，上层系统可直接使用该序列进行任务下发和调度
records List<SearchRecord>
详细的搜索记录列表，用于生成规划报告、甘特图、时间线分析等
totalScore double
规划总得分，可用于后续评估不同规划策略的效果
executionCount int
实际执行的任务数量，等于 taskSequence.size()
message String
规划结果描述信息或终止原因，帮助上层系统理解规划停止的原因

LianyiQueryParam（涟漪模型查询参数）

centerLon double
搜索中心点经度，范围 -180.0 到 180.0
centerLat double
搜索中心点纬度，范围 -90.0 到 90.0
entityID String
目标实体标识，不同目标可能有不同的运动模型参数
targetLastFindTime String
目标最后被发现的时刻，涟漪模型据此计算扩散半径
scoutTime String
当前侦察时刻，涟漪模型以此时间为基准计算概率分布
speed double
目标估计速度，速度越大，涟漪扩散范围越广
taskIDs List<TaskParam>
已执行的搜索任务列表，涟漪模型据此剔除已搜索区域

LianyiResultNew（涟漪模型计算结果）

lianyiPoints List<LianyiPoint>
主 Polygon 外轮廓顶点列表，按顺序连接形成闭合多边形
excludeGeos List<ToClientGeo>
主 Polygon 内部的洞列表，每个洞表示目标不可能存在的区域
area double
涟漪区域的总面积（单位: 平方米），用于概率归一化

LianyiPoint（涟漪点）

x double
经度 (Longitude)，范围 -180.0 到 180.0
y double
纬度 (Latitude)，范围 -90.0 到 90.0

ToClientGeo（客户端地理区域）

lianyiPoints List<LianyiPoint>
构成该区域外轮廓的顶点列表，按顺序连接形成闭合多边形

PlannerState（规划器状态）

currentTime LocalDateTime
当前规划时间，模拟时间推进的"虚拟时钟"
historyTasks List<TaskParam>
已执行的任务列表，输入给涟漪模型计算已搜索区域
candidateTasks List<TaskParam>
未执行的任务列表，每轮循环筛选评分后选择最优任务
taskSequence List<TaskParam>
最终任务序列，按执行时间排序，输出给上层系统

TaskCandidate（候选任务）

task TaskParam
原始任务参数，包含 taskID、satellite、scoutTime、catas 等
grid Grid
该候选任务关联的目标网格，包含 geometry 和 probability
coverage Geometry (JTS)
任务覆盖区域与当前 Ripple 的相交几何，表示有效搜索区域
accessTime LocalDateTime
任务的访问/执行时间，用于计算 TimeWeight
score double
综合评分，score = probability x effectiveCoverageArea x timeWeight

Grid（全球网格单元）

id String
网格唯一标识符，推荐使用 H3 索引、Geohash 或自定义行列号
geometry Geometry (JTS)
网格的几何形状，通常为 Polygon，坐标系为 WGS-84
probability double
目标存在于该网格的概率，取值范围 0.0 到 1.0

配置信息

application.yml 中的关键配置项：

规划算法流程

RippleTaskPlanner 采用贪心策略进行任务规划，核心流程如下：

Step 1 - 初始化 PlannerState，设置 currentTime = startTime
Step 2 - 根据 historyTasks 构造 LianyiQueryParam，调用涟漪模型
Step 3 - 涟漪模型返回 LianyiResultNew（概率分布区域）
Step 4 - GridService 初始化网格，ProbabilityService 计算各网格概率
Step 5 - AccessService 基于 candidateTasks 和当前 Ripple 计算候选任务
Step 6 - TaskScoreService 对每个候选任务进行综合评分
Step 7 - 选择 score 最高的任务，加入 historyTasks 和 taskSequence
Step 8 - 更新 currentTime = 已选任务的 scoutTime，candidateTasks 移除已选任务
Step 9 - 重复 Step 2-8，直到 candidateTasks 为空或所有 score 为 0

评分公式（第一版）：score = probability x effectiveCoverageArea x timeWeight
其中 timeWeight = 1 / (1 + 等待时间秒数)
